I spend my days keeping industrial production lines running (16 years in maintenance & reliability, CMRP · PMP · MBA · DBA), and my evenings building apps and platforms: mobile apps in Flutter and Swift, web platforms in Python, all self-hosted on my own home server in Riyadh 🇸🇦.

## 🚀 What I'm building

| Project | What it is | Stack | Status |
|---|---|---|---|
| ✈️ **[Vaeroly](https://vaeroly.com)** | A crew centre for virtual airlines: bookings, SimBrief dispatch, live ACARS tracking, flight scoring, ranks, events and Discord integration, for many airlines on one platform | Python · FastAPI · SQLite · Discord · PayPal | 🟢 Live |
| 📖 **القرآن نور · Quran Radio** | A multilingual Islamic app with live Quran radio | Flutter | 🟢 On the App Store & Google Play |
| 🛫 **SimBrief Flight Status Bot** | Discord bot that links SimBrief pilots and posts live flight status (takeoff, cruise, landed) | Discord · SimBrief API | 🟢 Live |
| 🛠️ **MTracker** | A CMMS for tracking machine maintenance | Flutter · Laravel | 🔧 In development |
| 💳 **SubTrack** | A subscription tracker app | Flutter | 🔧 In testing |
| 🖥️ **Self-hosted infrastructure** | My own home server running my sites and apps behind Cloudflare Tunnel, with automated deploys, encrypted off-site backups and Wi-Fi failover | Ubuntu · nginx · Cloudflare · systemd | 🟢 Live |
